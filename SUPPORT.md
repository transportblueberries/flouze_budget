# Support

Flouze Budget is an early-stage open-source project. The repository is the main place to report problems, suggest improvements and ask project-related questions.

## Bug reports

Use the **Bug report** issue template and include:

- what you expected to happen;
- what actually happened;
- steps to reproduce the problem;
- screenshots or logs when useful, with sensitive information removed.

## Feature requests

Use the **Feature request** template and explain the student problem you are trying to solve before proposing a specific implementation.

## Security issues

Do **not** report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Contributing

If you want to help build Flouze Budget, see [CONTRIBUTING.md](CONTRIBUTING.md) and the repository's `good first issue` items.

For the live project, visit [flouze.ch](https://flouze.ch).
