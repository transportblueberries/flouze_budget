# Security Policy

Security matters for a budgeting and personal-finance project, even at an early stage.

## Reporting a vulnerability

Please **do not open a public issue** for a suspected security vulnerability or for anything that could expose personal or financial data.

Use GitHub's private vulnerability reporting feature if it is available for this repository. If it is not available, contact the maintainer privately through their GitHub profile and include only the minimum information needed to reproduce the issue.

When reporting a vulnerability, please include:

- a clear description of the issue;
- the affected component or page;
- reproducible steps where possible;
- the potential impact;
- any suggested mitigation, if known.

Please avoid including real credentials, account details, financial records, API keys, tokens, or other sensitive personal data in a report.

## Scope

Flouze Budget is currently an early-stage project. Security reports are welcome for any code or documentation published in this repository.

## Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
