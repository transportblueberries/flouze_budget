# Contributing to Flouze Budget

Thanks for your interest in contributing.

Flouze Budget is an early-stage, student-led open-source project. Contributions of all sizes are welcome.

## Good first contributions

You do not need to be an experienced developer to help. Useful contributions include:

- fixing typos or improving documentation
- suggesting clearer wording or UX improvements
- reporting bugs
- improving accessibility
- proposing budgeting features useful to students
- adding or improving tests
- contributing code fixes or features

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make a focused change.
4. Test it when applicable.
5. Open a pull request explaining what you changed and why.

Please keep pull requests small and focused where possible. This makes them easier to review and merge.

## Issues

Before starting a larger change, open an issue first so we can discuss the idea and avoid duplicated work.

## Pull requests

A good pull request should:

- solve one clear problem
- explain the motivation for the change
- avoid unrelated changes
- include screenshots when the UI changes
- mention how the change was tested, when applicable

## Conduct

Be respectful and constructive. This project should remain welcoming to students, first-time contributors and experienced developers alike.
